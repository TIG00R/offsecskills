# CWE Top 25 (2025)

The 2025 MITRE/CISA ranking (CVEs disclosed June 2024–June 2025). Put the CWE ID
on every finding. A CWE appearing here raises likelihood; one also on the CISA KEV
list raises it further. Ranks are from the official list — never renumber them.

## Using this file

- Match a confirmed finding to the most specific CWE (e.g. CWE-89 over CWE-77 for
  SQL). Several here map straight to access control (862, 863, 284, 639, 306) and
  to injection (79, 89, 78, 94, 77).
- Memory-safety CWEs (787, 416, 125, 120, 121, 122, 476) concentrate in C/C++,
  unsafe Rust, and FFI — see `languages/c-cpp.md`, `languages/rust.md`.
- Check KEV membership for a confirmed CWE to justify a severity bump.
